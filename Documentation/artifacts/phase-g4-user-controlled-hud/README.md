# Evidence from the Android emulator

Screenshots are actual runtime frames. The Phase F harness script advances the game, so 3D images are presentation and activation evidence only, not manual gameplay validation.

- `g4-stadium-selection-hidden.png` and `g4-team-select-controls-hidden.png`: original front-end screens show no gameplay controls.
- `g4-context-selector.png`: mobile context selector over the original game screen.
- `g4-context-selector-open-play.png`: selector over a rendered match scene.
- `g4-active-classic-joystick-final.png`: user-selected Classic Joystick context in a rendered match frame, after moving controls clear of the lower score area. It does not prove a cricket action was accepted.
- `g4-cutscene-no-controls.png`: celebration/cutscene scene with controls hidden.
- `g4-cutscene-swipe-context-suppressed.png`: user selection is suppressed when renderer reports a menu-like/cutscene context.

`g4-batting-classic-joystick.png` is an earlier pre-relocation capture and is retained only as development history; do not use it as final layout evidence. The active match screenshots are scripted progression, not a human-played match.
