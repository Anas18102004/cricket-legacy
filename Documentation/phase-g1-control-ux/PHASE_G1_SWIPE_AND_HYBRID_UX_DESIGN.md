# Phase G.1 Swipe and Hybrid UX Design

**Runtime status: NOT ENABLED.** Phase G accepted a swipe in any area outside its native button/joystick regions and could dispatch input regardless of actual match context. The four named batting modes do not have distinct native processing paths.

G.1 suppresses mobile gesture processing unless an explicit batting context is set. Swipe trail and permanent mode indicator are hidden with the overlay. No visual feedback or hybrid interaction is enabled in menus, bowling, fielding or unknown scenes. A future implementation needs a verified batting observer and explicit mode-specific rules before these controls can be safely shown.
